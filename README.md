# Markdown Workbench S

A feature-rich Markdown preview extension for Visual Studio Code, with **powerful table filtering and sorting** at its core.

Markdown Workbench S is designed for reading and working with technical Markdown documents while keeping useful document tools close at hand.

## Highlights

### Powerful table filtering and sorting

Tables are a core feature of Markdown Workbench S.

- Filter table columns
- Sort columns in ascending or descending order
- Freeze the first column, header row, or both
- Resize table columns
- Resize tables
- Reset column widths and table size
- Copy table data
- Export tables as CSV

### Markdown preview

- Table of Contents with search
- Full-text document search
- Syntax highlighting
- Code block copy, wrapping, and collapse
- Mermaid diagram rendering
- Light, Dark, High Contrast, and System themes
- English and Japanese interface
- Collapsible sidebar

### Preview-to-source navigation

Double-click a rendered block in the preview to jump to the corresponding location in the Markdown source.

### Local-first architecture

All runtime libraries are bundled with the extension. Markdown Workbench S does not require a CDN or external API for its core preview functionality.

## Usage

1. Open a Markdown file in VS Code.
2. Run **Markdown Workbench S: Open Preview** from the Command Palette, or use the editor title/context menu.
3. Use the preview tools to inspect, filter, sort, and navigate your document.
4. Double-click a rendered preview block to reveal its source location.

## Supported file extensions

- `.md`
- `.markdown`
- `.mdown`
- `.mkdn`
- `.txt`

## Development

Clone the repository and open it in VS Code. Press `F5` to launch an Extension Development Host.
